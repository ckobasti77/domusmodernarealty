# 00: Brief and decisions (agreed with the owner, 2026-09-27)

## The client
Mihajlo runs a real-estate agency in Serbia. "Mihajlo Estate" is the working brand name; it is editable in admin and appears in the logo, copy and meta. The market is all of Serbia with **Belgrade as the primary focus** (Novi Sad, Niš, Kragujevac, Subotica, Kopaonik/Zlatibor as secondary locations).

## What we are building
1. **A public website that looks like an award winner** in the "Editorial luxury" style.
   - Dark cinematic hero, ivory/charcoal/bronze palette, large serif display type.
   - Slow, confident GSAP choreography with Lenis smooth scroll.
   - A fully animated landing page, not just a hero.
2. **A real product behind it:**
   - search with filters and a map
   - listing pages with gallery, floor plans, 360°/3D, calculators and viewing booking
   - valuation and "sell with us" funnels
   - agents, neighborhoods, journal, favorites and compare
   - legal pages
3. **A full admin panel (CMS + light CRM):**
   - listings with media, translations, legal/mandate fields and publishing workflow
   - leads inbox and pipeline, viewings calendar
   - team and roles, locations, journal
   - site content, settings, analytics, activity log
4. **Immersive tours as an optional per-listing premium service (beta now):**
   - (a) Street-View-style 360° tour (self-hosted Photo Sphere Viewer, or a Matterport/Kuula embed)
   - (b) a game-like 3D walkthrough (arrow keys/WASD) of a Gaussian-splat scan made with MipMap / Scaniverse / Postshot from a 360° camera video
   - See `06-3D-TOURS.md`.

## Decisions
| Topic | Decision |
|---|---|
| Business model | Agency website. Only staff publish. Public "submit your property" creates a lead, not a listing. |
| Languages | sr-Latn (default, `/sr`), en, ru, de. Admin in Serbian. |
| Visual direction | Editorial luxury. Tokens are in `03-DESIGN-SYSTEM.md`. |
| Backend | Convex (already connected; dev deployment in `.env.local`) |
| Auth | `@convex-dev/auth` Password, invite-only, roles admin / manager / agent / editor |
| Maps | MapLibre + OpenFreeMap (no keys, free) |
| Currency | EUR primary. Optional RSD display using a rate set in admin. |
| Hosting (later) | Vercel + Convex production (not tonight) |
| Media | Hero video and key visuals generated by the owner's AI tools may appear in `media-src/`. Otherwise use verified Unsplash photos from `docs/assets/demo-media.json`. |
| 3D | Build now as beta: 360° viewer + splat walk viewer + Matterport/Kuula embed + admin fields |
| Demo data | ~30 realistic listings across Belgrade + other Serbian cities, flagged `isDemo`, 4 languages |
