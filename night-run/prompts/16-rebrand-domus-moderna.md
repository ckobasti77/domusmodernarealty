# Step 16: Rebrand to Domus Moderna Realty — the new logo everywhere

**Read:** `brand/README.md` (the new identity, files, colours, minimum sizes), `components/site/Logo.tsx` and every file that imports it, `lib/seo.ts`, `lib/og.tsx`, `app/icon.svg`, `app/apple-icon.png`, docs/03-DESIGN-SYSTEM.md §4, docs/04-CONTENT.md.
**Skills:** `frontend-design`; `impeccable` if present (visual check). The `logo-design` skill may be used for checks only — never to redraw the logo.

## Context
- The agency's name is now **Domus Moderna Realty** (short form **Domus Moderna**). "Mihajlo Estate" was a working name and is retired everywhere a visitor, an agent or a search engine can see it.
- The owner approved a new identity. The master files are in `brand/` (committed before this step):
  - a 3D "portal D": the D with an arched doorway, extruded like a bronze monument;
  - a circular seal, "DOMUS MODERNA · REALTY · BEOGRAD" around the 3D D;
  - a two-line wordmark: DOMUS MODERNA (EB Garamond 500 caps) over REALTY (Manrope 600);
  - icons and a default OG image.
- **Use the files verbatim.** Copy their path data into components. Never redraw, retype, re-space or re-centre the logo. Never set the name in a live font where the logo is meant.
- If `brand/` or this prompt show up as uncommitted at the start, commit them first as `chore(brand): add Domus Moderna brand files`.

## Tasks

### 1. Logo components (`components/site/Logo.tsx`)
Rebuild the file around the new art and keep the existing exports, so call sites keep compiling.
- **`Logo`**: the horizontal lockup (`lockup-horizontal-*`).
  - `tone`: `"dark"` (on dark surfaces), `"light"`, `"current"` (mono, currentColor).
  - New prop `descriptor` (default `true`). `false` gives the compact lockup without REALTY (`lockup-compact-*`).
  - Keep `rule` as an accepted no-op, or remove it together with its call sites.
- **`Mark`** (new): the 3D D (`mark-3d-*`). `variant="flat"` gives the flat D (`mark-flat-*`), which is required at 24 px and below.
- **`Seal`** (new): `seal-*` in on-dark, on-light and mono. A `flat` option uses `seal-flat-mono`.
- **`Monogram`**: keep the export name and render the new D (flat when small). Update its doc comment.
- Inline SVG only (no `<img>`, no font dependency).
  - Keep the current accessibility pattern: `role="img"` with `aria-label="Domus Moderna Realty"`, or presentation when the parent link already names it.
- Colours come from `brand/README.md` and match the existing tokens: ink, ivory, bronze, bronze-text.
