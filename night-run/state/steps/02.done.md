## Decisions

All nine are appended to `docs/DECISIONS.md` with their reasons. The ones that
change how later steps write code:

1. **Font variables are `--font-*-family`**; the Tailwind `@theme` keys
   `--font-display` / `--font-sans` / `--font-mono` wrap them. Use the Tailwind
   utilities (`font-display`, `font-sans`, `font-mono`), never the raw variables.
2. **`cn` is imported from `@/lib/utils`** (which re-exports the `cn` package).
   There is no `lib/cn.ts`, contrary to the ARCHITECTURE §2 file map.
3. **shadcn's `:root`/`.dark` hold the admin theme.** `--primary` is
   `#8C6D3F` (bronze-deep, 4.67:1 on paper) because `#B08D57` fails AA.
   Public components must use the brand utilities (`bg-ink`, `text-ivory`,
   `text-bronze`, …) and never `bg-background`/`text-foreground`.
4. **`components/ui/form.tsx` is hand-ported** from the `new-york-v4` style —
   the radix-nova registry item for `form` ships no files.
5. **Media queries go through `useSyncExternalStore`**, because
   `react-hooks/set-state-in-effect` is an error in this eslint config. Any new
   hook that reads `matchMedia` must follow the same shape.
6. **`proxy.ts` imports `createMiddleware` from `next-intl/middleware`** — 4.14.7
   has no `next-intl/proxy` export.
7. **ICU plural fixes** landed in `card.rooms`, `compare.limitReached` and
   `listing.viewGallery` across all four locales.

## Known issues

- **A stale `next start` on port 3000 silently serves an old build.** The first
  `npm run test:e2e` run failed with `Timed out waiting 180000ms from
  config.webServer` for exactly this reason, and a manual probe then showed
  `/sr → 404`. Both cleared after killing the listener. Before any e2e or
  screenshot run: `netstat -ano | grep ":3000 " | grep LISTENING` and
  `taskkill //F //PID <pid>`.
- **Git Bash rewrites leading-slash arguments.** `node scripts/shots.mjs --routes
  /sr,...` turned `/sr` into `C:/Program Files/Git/sr`. Always prefix the command
  with `MSYS_NO_PATHCONV=1 MSYS2_ARG_CONV_EXCL='*'`.
- **`public/media` is 35 MB**, above the plan's 30 MB soft target. Accepted and
  logged; see DECISIONS.md for the encoder settings behind it.
- **`components/admin/LoginForm.tsx` submits nothing yet.** Its `onSubmit` is a
  no-op placeholder until step 03 wires `useAuthActions().signIn("password", …)`.
  Same for `AdminProviders`, which uses `ConvexProvider` where step 03 needs
  `ConvexAuthProvider`. Both are marked with comments naming step 03.
- **`app/[locale]/page.tsx` is a placeholder.** It is on-brand and renders a glyph
  specimen so screenshots prove the subsets, but step 05 replaces it wholesale.
- **`lib/media-manifest.json` has no consumer yet.** `lib/media.ts` (`getMedia`,
  null-fallback to `lib/demo-media.ts`) is step 05's first task, per
  IMPLEMENTATION-PLAN §1.7.
- No TODO comments were left in the codebase.

## Next steps should know

- **Verified against the installed packages, not from memory:** `next/root-params`
  exists in 16.3 and its getter is `string | undefined` under multiple root
  layouts; `error.tsx` takes `{ error, retry }` in 16.3; `global-not-found`
  requires `experimental.globalNotFound` plus a full HTML document;
  `getRequestConfig`'s `requestLocale` is deprecated in favour of root params;
  `lenis/react` exports `ReactLenis` + `useLenis` + `LenisRef`.
- **next/font rejects spread arrays.** `subsets: [...SUBSETS]` fails the build
  with "Unexpected spread"; every option must be a literal.
- **Routing facts:** the public tree is prerendered at `/sr-Latn`, `/en`, `/ru`,
  `/de`, and the proxy rewrites `/sr → /sr-Latn`. `/` 307s to the detected locale.
  There is no `app/page.tsx` and there must not be one.
- **Locale-aware links** come from `@/i18n/navigation` (`Link`, `redirect`,
  `usePathname`, `useRouter`, `getPathname`), never from `next/link`, except in
  `global-not-found.tsx` which has no locale.
- **The CSP is already live on every response.** Adding a new third-party host
  (a splat CDN, an analytics script, a tour iframe) means editing `lib/csp.ts`
  and nothing else; the e2e suite asserts the header is present.
- **`npm run verify` now starts with a real Convex push** against
  `youthful-avocet-278` (dev). `convex/` still holds only `_generated`, so
  `Doc` is `any` until step 03 writes `schema.ts`.
- **Admin strings are literals in Serbian**, deliberately not in `messages/*`.
- The i18n-translator agents flagged source-copy issues that are *not* bugs but
  need an owner decision, carried forward to step 04/05: `home.introSignature`
  asserts "od 2014.", `home.valuationLede` claims valuations are based on real
  transactions, and `docs/04-CONTENT.md` prescribes capitalised "Vi/Vaš" while
  the messages use lowercase. Long-string overflow candidates: `de`
  `listing.bookViewing`/`addToCompare`, `ru` `legal.cookiesHeading` and
  `units.floorHighGround`.
