# Step 04 done — Design system, UI kit, shell

## Summary

The public site went from a token file plus a placeholder page to a complete,
shipped design system: finalized tokens with a computed WCAG pass, an SVG
wordmark and monogram, 18 site components, 11 motion primitives, the whole shell
(header, mobile menu, footer, consent, preloader, page transition) and an
internal `/[locale]/styleguide` that shows every component and state in any of
the four locales.

The `design-critic` agent ran three times. Pass 1 returned 30 findings
(6 high, 13 medium, 11 low); pass 2 returned 4 high; pass 3 returned 1 high.
Every high and every medium was fixed and individually re-verified in a live
browser. The last pass also confirmed the earlier fixes against the pixels.

Two of the findings were defects that would have shipped to production and that
no test would have caught on its own:

- **Google's Cormorant Garamond has no precomposed lowercase Serbian carons.**
  Its latin-ext subset ships uppercase Č Ć Š Ž Đ but not č š ž, so Chrome
  composed them from U+030C and parked the caron at cap height. "Vračar",
  "život" and "Niš" rendered with the mark floating detached above the letter at
  every size, in the display face, on a Serbian real-estate site. The face is
  EB Garamond now, and `tests/e2e/smoke.spec.ts` measures the lowercase-vs-
  uppercase caron ascent so it cannot come back.
- **`cn` silently dropped a colour class.** The stock `cn` export only knows
  Tailwind's own scales, so it lumps every unknown `text-*` utility into one
  conflict group — and this project has custom `text-*` font sizes next to
  custom `text-*` colours. `cn("bg-ivory text-ink", "h-[52px] text-small")`
  returned `bg-ivory h-[52px] px-8 text-small`, which rendered the primary
  cookie-banner button ivory-on-ivory.

## Decisions

All in `docs/DECISIONS.md` (19 entries for this step). The ones later steps must
respect:

1. **Three colour tokens exist only to pass AA for normal-size text**:
   `--color-bronze-text` #7A623C, `--color-warning-text` #835F22,
   `--color-success-text` #476E51, plus a darkened `--color-stone-text` #6C655B.
   `--color-bronze` #B08D57 is 2.70:1 on ivory — it may carry text ONLY on the
   ink family, or sit behind ink text as a fill.
2. **`cn` comes from `lib/utils.ts`, backed by generated tables.** Re-run
   `npm run cn:tables` after adding a theme scale or a new utility.
3. **`prefetch={false}` on every link to a route steps 06–10 will create.**
   Step 10 should delete the prop once the routes exist.
4. **EB Garamond, `font-normal` not `font-light`** (its variable range starts at
   400). DESIGN §2 still names Cormorant and should be amended.
5. **`--consent-h`** is published by the banner; `body` and any full-height hero
   must add it to their bottom padding.
6. **Control boundaries are 30–40% alpha, never the 12% hairline** (WCAG 1.4.11).
7. **Rich-text messages need `t.rich` AND a non-flex container.**
8. **The header's solid state comes from `onUpdate`, never `onToggle`.**
9. **`SplitText` is created with `reduceWhiteSpace: false`** so the non-breaking
   spaces survive line measurement.

## Known issues

- **The landing page is still a placeholder.** It has no hero media, and at 1440
  the hero is type on the left with empty ink on the right. Step 05 replaces the
  page with the 13 choreographed sections; this step only had to prove the shell
  and the components.
- **Demo card photography is cold and ceiling-heavy.** The verified pool has
  90 photos for ~220 gallery slots and 22 listings whose first category is
  `living`, so cards repeat and several crops are mostly ceiling. Step 06 task 0
  merges 94 more verified photos and re-seeds; consider
  `object-position: 50% 65%` on the card media at the same time.
- **Remaining design-critic items, all medium or low, none blocking:**
  - `SectionHeading`'s `action` is bottom-aligned to the title, so it floats
    mid-band on a 4-line heading; DESIGN §6.4 wants a text link there, not an
    outline button.
  - Card rows do not align across a row when one title wraps to 2 lines and
    another to 1 (`line-clamp-2` + `min-h-[2lh]` on the title would fix it).
  - Gallery arrows and the `1 / 5` counter are always visible; they should be
    hover-gated on fine pointers.
  - The form reserves no fixed space for the error slot, so field gaps shift
    between 53 and 81px; text inputs run the full 656px at 1440.
  - The styleguide's price band uses `€/m²` as a section heading.
  - The footer's KONTAKT column mixes contact details with the commission and
    tax paragraph, and uses `text-stone` (an ivory-surface token) on ink.
  - No screenshot captures a focus state, so the bronze focus ring is verified
    only from the CSS and by hand.
- **`lib/format.ts::SQUARE_METRE` duplicates `units.m2`** from the messages.
  Callers that hold a translator pass `t("m2")` explicitly; the map is the
  fallback for pure modules. Keep the two in sync.
- **A parallel session was editing this repository.** `git add -A` in commit
  `13fd8f1` swept in three `night-run/prompts/*.md` edits and
  `docs/assets/demo-media-additions.json` that this step did not author. The
  content is intact and committed; it was left alone rather than rewriting
  history under a live session. Later commits used targeted `git add`.
- No TODO comments were left in the codebase.

## Next steps should know

- **`components/site/*` is the public kit; `components/ui/*` stays the admin's.**
  `components/site/Tabs.tsx` wraps Radix so the roving tabindex is not
  re-implemented; `components/site/Button.tsx` exports `buttonClasses` because
  localized navigation has to go through next-intl's `<Link>`.
- **Every motion component follows one shape:** `useGSAP` + one
  `gsap.matchMedia()` with `MOTION_QUERIES.desktop` / `.mobile` / `.reduced`,
  and the reduced branch paints the final state instead of animating toward it.
  Copy `components/motion/Reveal.tsx` when adding another one.
- **Never `autoAlpha` on anything that must receive focus.** It writes
  `visibility`, and `useGSAP`'s layout effect runs before the effect that calls
  `.focus()` — that silently broke the mobile menu's focus move.
- **An overlay inside a positioned ancestor is trapped in its stacking context.**
  The mobile menu is a child of `<header>`, so the header lifts to `--z-menu`
  while it is open.
- **`PropertyCard` accepts an optional `images` array.** `listingCardV` only
  carries `cover`; the carousel chrome renders only with 2+ frames. The
  styleguide pulls real galleries with `listings.detailsByIds` (the field is
  `media`, not `images`).
- **Stores:** `useFavorites()` / `useFavoriteCount()` / `useFavorite(id)` and
  `useConsent()` → `{ decided, categories }`. Analytics and marketing scripts
  must gate on `useConsent()`; nothing but `necessary` is true until the visitor
  chooses.
- **`fixOrphans(text)`** binds one-letter Serbian and Russian prepositions.
  Apply it to any prose that is not already going through `SectionHeading` or
  `SplitReveal`.
- **`npm run cn:tables`** after touching `@theme` in `app/globals.css`.
- **`node scripts/shots.mjs` needs `MSYS_NO_PATHCONV=1`** in Git Bash, or a
  leading-slash route is rewritten to a Windows path. Give every valued flag a
  value.
