## Known issues

- **Search scale ceiling (~500 listings per transaction).** `count` reads up to 600 documents with one `take()`, and `mapPoints` up to 1,000 (`MAX_POINTS`). At ~10–15 KB per listing document, that approaches Convex's per-query read budget (~8 MiB) past roughly 500 listings in one scope.
  - The fix is a slim `listingSearch` projection table holding only the filter fields, coordinates, price and cover URL, kept in sync in the same mutations as `listings`. `count`, `mapPoints` and the post-filtered windows would then scan it instead. Not needed for the demo (30 listings) or a typical agency catalogue.
- **Post-filtered pages can be short.** A selective filter reads a 120-document window per page. The client reads up to 8 more windows automatically; past that on a huge catalogue, "Prikaži još" continues by hand.
- **Price or area range + a non-matching sort** now reads the sort's index and post-filters the range. That is correct, but on a large catalogue with a narrow range it scans more. A `by_scope_and_cityId_and_publishedAt` / `…municipalityId_and_publishedAt` index would serve "one place + newest" fully (auditor L4).
- **Design items deliberately not taken (pass 2):**
  - Hiding the chip row on desktop (PRD A3 asks for active chips).
  - Hide-on-scroll for the site header on phones: a Header-wide behaviour for all pages, better done in the step-12 polish.
  - Sentence-case for the transaction switch (DESIGN §4 buttons are uppercase).
  - A 22 px container-query title size.
  - A 44 px thumb hit area on the sliders.
- **Long titles still end in an ellipsis on 3:2 cards** (e.g. "…na Kosančićevom vencu,…" and many RU titles). This is content: shorter seed titles, plus an admin character counter (step 08), are the fix.
- **Content inconsistencies** seen in screenshots, left for step 08 content work:
  - EN "Blok 70" (title) vs "Block 70" (location);
  - "Cvetkova pijaca" vs "Pijaca";
  - a few demo photos that don't fit their titles.
- **The RU map shows municipality names with "(ОПШТИНА)"** from OSM data.
- **`/uporedi`** is linked from the compare tray, but the page is step 10. Until then the link 404s (`prefetch={false}`).
- **`/kontakt?message=…`:** the empty-state CTA passes a prefilled `message` query param. The contact page (step 10) must read it into the message field.
- **Lint:** 12 pre-existing warnings remain in `convex/listingsAdmin.ts` (intentional `_drop*` destructuring) and `convex/auth.config.ts`. This step removed the two dead imports (`agents.ts`, `toursAdmin.ts`).
- No TODO comments were left in the code.
