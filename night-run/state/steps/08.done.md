## Decisions

All 17 are logged in `docs/DECISIONS.md` as `[08]` entries dated 2026-09-30.
In brief:

- **Publish checklist context.** A hidden agent blocks publishing. The registry number is a warning while the settings are demo and a blocker once they are real.
- **Preview links.** They expire server-side through a scheduled job. They live on the existing public route, with noindex, no forms and no view tracking.
- **Duplicates never share a storage blob.** The copy also drops the contract, owner, verification and uploaded 3D/OG refs.
- **Agents in the admin see only their own listings**, via their own index. Others' listings stay readable on the public site.
- **Nominatim runs in a staff-only Convex action** with an identifying User-Agent and a 1 req/s global plus per-user limit.
- **"Documents verified" is stamped by the server.** The seller is a private contact, set only through `setOwner`.
- **Step-09 sections show as "uskoro"** in the sidebar.
- **Admin errors show the server's Serbian message.** Login failures use one generic message.
- **Emptied optional fields are cleared** through `update({ unset })`. The place ids must form one chain.
- **Autosave is a tested engine class.** It sends dirty keys only, one save at a time, merges server changes, holds price/slug while focused, and flushes before publish or leaving.
- **Design pass 1 changes:**
  - the table layout and phone list;
  - dot status badges;
  - accessibility tokens: ring, 3:1 borders, a solid focus outline, 44 px targets;
  - Manrope for shadcn titles;
  - a demo-data banner.
- **The unused-vars lint rule ignores rest siblings and `_` names.** Lint now has zero warnings.

## Known issues

- **OpenFreeMap was unreachable again from this machine.** The editor's map picker shows "Učitavanje mape…" and then, after the 12 s deadline, its "Mapa trenutno nije dostupna — unesite koordinate ručno" notice. The coordinate inputs and the address search (Nominatim through Convex) work without it. The pin click/drag was built against `@vis.gl/react-maplibre` but could not be exercised in a browser here. Re-check when the tile server answers.
- **Status and demo counts are bounded scans.**
  - `listingsAdmin.counts` reads up to 8 × 501 full listing documents per call (convex-auditor M5). With ~13 KB per listing that reaches the 16 MiB read limit around 1,250 listings.
  - The fix is denormalized per-status (and per-agent+status) counters in `applyCountDelta`, or `@convex-dev/aggregate`.
- **`deleteListingCascade` caps its child reads** (500 view rows, 200 leads, 100 viewings, 60 scenes/price changes). A listing past those caps leaves orphans (convex-auditor M3). Each deletion now runs in its own transaction, but a self-rescheduling batched cascade is the durable fix. Tour pano and splat blobs are not deleted.
- **The e2e run leaves audit rows.** `activity` rows for the e2e invite and user ("Pozivnica prihvaćena · e2e+agent-…") stay and show in the dashboard's recent activity. The activity log is append-only by design. A few admin auth sessions also accumulate per run (the agent's are purged).
- **Owner contact edits** have their own "Sačuvaj vlasnika" button. They are not covered by the leave-page guard.
- **The editor's `now`** (checklist and preview expiry) is fixed when the editor opens. A tab left open for days shows a stale expiry until reload.
- **A failed `media.attach`** after a successful upload leaves an unreferenced blob. There is no `discardUpload` mutation or storage-GC cron yet.
- **Room tag cannot be reset to "none"** (`media.updateMeta` has no unset).
- **Admin wording vs. DTO:** the "street" address visibility is labelled "Samo ulica, približan pin", but the public DTO hides the street name for `street` too. One of the two should change; the owner should decide which.
- **Sidebar "uskoro" items:** the design critic suggested hiding them. They stay until step 09 builds those screens.
- **The full e2e suite is load-sensitive on this machine.**
  - 6 mobile cases failed once with "browser has been closed" / `ERR_ABORTED` during the 7.7-minute full run, and passed on `--last-failed`.
  - Run `admin.spec.ts` alone, or with `--workers=2`, when the machine is busy. `search.spec.ts` counts listings, so it can also flake if it overlaps the admin flow's publish window.
- No TODO comments were left in the code.
