## Decisions

All are in `docs/DECISIONS.md` as `[10]` entries dated 2026-10-01. In brief:

- **On-site valuation** is a callback request on the same lead, written by the earlier attempt.
- **Legal "Nacrt" notice** appears in the admin only.
- **Settings placeholders** in managed texts are filled from the public settings.
- **One page frame** for all content pages.
- **Seller form:** the visitor picks a place from the tree OR types a street; at least one is required.
- **Sell page** reuses the landing's `ProcessSteps` and the about page's `Straddle`.
- **Prefetch:** `prefetch={false}` is removed except on `PropertyCard`.
- **`useListingsById`** keys its memo on the function name. Any hook that memoizes on an `api.*` reference must do the same.
- **Unknown paths** go through a `[locale]/[...rest]` catch-all that calls `notFound()`.
- **Design-critic items:** what was fixed and what was deliberately not taken are both listed.
- **`RangeField`** re-seeds only the bound that changed.
- **Landing axe test** waits 2 s after its scroll pass.

## Known issues

- **A `notFound()` 404 is server-rendered as Next's `<html id="__next_error__">` document,** and the localized not-found UI is painted from the RSC payload on the client.
  - The status is 404, `noindex` is set, and the `<title>` is localized in the HTML.
  - The `<h1>` and `<html lang>` are not in the server HTML.
  - This was already the case for every `notFound()` route before this step (listing, location, agent, article), and is not caused by the catch-all.
  - **Step 12 (SEO) should investigate.** Possible causes are the locale layout's dynamic APIs or the `globalNotFound` flag.
- **Full e2e suite under `--workers=2`:** 220 passed and 2 failed, both from cross-spec interference that predates this step. Both pass when run serially.
