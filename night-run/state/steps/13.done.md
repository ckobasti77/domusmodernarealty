## Known issues

- **PLC-14 (low, accepted)**: the team/agents pages show ink monogram tiles until the owner uploads real photos. This is required by the no-stock-faces rule.
- **404 server HTML (low, known since step 10)**: `notFound()` pages render Next's error shell on the server (no `lang`/h1 in the HTML). Status 404, `noindex` and the localized title are correct, and the UI paints on the client. Re-investigated with a dev server: the fallback is thrown at the root because of the two root layouts; turning off `globalNotFound` does not change it; a Suspense wrapper would turn 404s into streamed 200s. Left as is.

  - In headless SwiftShader the search map can show a blank tile band where the fixed compare tray overlaps the canvas. That is a capture artifact (verified), not a defect.
- **Every finding with its verification** is in `.shots/qa-round1/findings.json` (gitignored, local only). The report's appendix lists them all with status.
- **Two e2e rules for this repo:**
  - `admin-crm.spec` now edits the hero **lede**, not the h1, because `landing.spec`/`shell.spec` assert the seeded h1.
  - `admin-modules.spec` deletes only its own `[E2E-M]` listings by id. `qa:purgeE2EListings` is global and would race other specs.
- **Settings changes in tests**: saving legal fields in Podešavanja re-evaluates `settings.isDemo`, which can block publishing in parallel specs. The admin-modules spec only touches office hours and restores them.
- **CRLF trap**: many files in the working copy are CRLF. A naive `s.replace("...\n...")` edit silently misses them. One `poweredByHeader` edit was lost that way and only the e2e header assertion caught it. Normalize line endings in edit scripts, or use the Edit tool.
- **Production server lifetime**: a backgrounded `npm run start` outlives its wrapper task when that task is killed. Stop it by PID (`netstat -ano | grep ":3000 "`, then `taskkill //F //T //PID <pid>`).
