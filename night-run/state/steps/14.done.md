## Decisions

All 23 are in DECISIONS.md under `[14]`. The ones that change how later steps work:

- Password auth is an explicit credentials provider; do not go back to the library's `Password` provider (its sign-up path is a password oracle).
- "Price on request" is removed, because Art. 18 requires the price on every ad.
- A public listing must pass the publish checklist after every edit:
  - drafts only get format and sign rules;
  - sold/rented listings skip the contract item;
  - contract dates are Belgrade calendar days.
- Demo adoption:
  - a duplicate of a demo listing is not demo;
  - attaching a real owner adopts a demo listing;
  - the purge keeps demo listings that hold uploads or real leads/viewings.
- Exact search paging supersedes [06]'s 120-document window.
- The rooms filter has a 4.5 chip.
- `viewings.request` returns `null`: a repeat request looks like success, and public callers get no ids.
- The favorites funnel is fed by an increment-only `stats.trackFavorite`.
- `alternateLinks: false` turns off next-intl's hreflang headers.
- `/sr-Latn/…` redirects with a 308 to `/sr/…`.
- The sitemap renders at request time, with its data cached hourly.
- `verify` runs `npm run check`.
- The e2e suite refuses a missing or stale build and reads `E2E_ADMIN_*` credentials.
- Admin: one leave guard for the whole panel, autosave isolates refused fields, number fields are text inputs, and pasted HTML is cleaned to the allowlist.
